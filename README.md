# MechToSpace

MechToSpace is a static, GitHub Pages-ready engineering learning site. It includes a responsive home page, project/venture sections, and eight interactive educational simulator pages.

## Run locally

Open `index.html` through a local static server (for example, `python -m http.server 8000`).

## GitHub Pages

Repository: `liveartshipit/mech-to-space`  
Custom domain: `mechtospace.com`

Enable Pages in **Settings → Pages → Deploy from a branch → main / root**. The `CNAME` file is included.

## Simulator limitations

The simulator pages in this repository are simplified educational models for exploring relationships between inputs and outputs. They are not certified engineering tools, flight-planning products, acoustic compliance calculations, or design approvals. Verify calculations independently before real-world use.
